## 서버컴포넌트에서 데이터 페칭

- 자바스크립트의 fetch api로 api요청을 보내서 페칭하기
- orm(드리즐, 프리스마)등의 라이브러리를 이용해서 연결된 db에 직접 가져오기

넥스트가 프론트로만 사용이 된다면 <br>
서버컴포넌트에서 데이터 페칭은 fetch api로 api요청을 보내서 응답을 받으면 됨

넥스트가 풀스택으로 사용이 된다면<br>
서버컴포넌트에서 데이터 페칭은 orm으로 쉽게 데이터 페칭하기(?)

## 클라이언트에서 데이터 페칭

- use 훅을 사용해서 서버컴포넌트에서 props등으로 클라이언트 컴포넌트로 넘겨준다.
	- 클라이언트에서 use훅을 이용해서 데이터를 받는다
	- ![](public/asset/posts/client%20data%20fetch.png)
- 혹은 SWR/tanstack query등을 이용해서 데이터를 관리한다.

## 스트리밍

스켈레톤 UI라고 불리는 것이 있다. <br>
데이터 페칭중에 로딩시 표시해줄 UI를 의미한다/

두가지의 스트리밍을 구현할 수 있다.

- 데이터 전체를 로딩될때까지 기다렸다가 전체를 출력하기
	- 라우팅 경로에 `loading.tsx` 파일을 만들면 해당 컴포넌트가 로딩될때 표시될 컴포넌트가 된다.
	- 이후 리액트의 `Suspense`컴포넌트를 이용해 `fallback` 속성에 `loading.tsx`을 넣어주면<br>
	  `Suspense`의 자식 컴포넌트가 로딩중일때 `loading.tsx`가 출력된다.
- 데이터가 로딩되는 순서대로 출력하기
	- 필요한 컴포넌트마다 `Suspense`컴포넌트를 붙혀주면 된다.
	- 그럼 차례대로 데이터 로딩이 되는대로 출력이 될것임.
